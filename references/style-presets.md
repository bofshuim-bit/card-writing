# 文风预设（按题材换）

> 文风规则不是万能套话。日常轻喜剧的禁令和仙侠、末世、悬疑完全不同。
> 用法：选一套，把「规则」改写成适合你那张卡的句子，塞进人设的【文风规范】模块。

---

## 通用：治 AI 腔（任何题材都加）

```
禁止句式：
· 「不是……而是……」——直接禁，不要用
· 「像……一样」「仿佛」「宛如」——整段最多用一个，且必须是日常事物（生活用品、自然物），不用"像被雷劈中"这种夸张比喻
· 「空气中弥漫着」「时间仿佛静止」「那一刻」「心中涌起」「嘴角勾起一抹弧度」
· 「一丝不易察觉的」「眼神深邃」「只见」「顿时」「不禁」「隐隐」
· 段尾总结腔：「这一刻，她明白了」「原来，一切都……」

写法：
· 长短句交替，连续三句长句必须切短
· 每段 3~6 句，对话段为主
· 情绪落身体：心跳、呼吸、手指、肩膀、语速——禁止直接写"他很伤心"
· 细节必须具体：便利店的热柜、自动贩卖机的哐当声、吉他弦的金属味
· 写动作不写情绪标签，写沉默不写心理分析
```

## 一、日常轻喜剧（校园、乐队、打工、合租）

```
基调：日常轻喜剧。环境每段一笔城市呼吸（街头艺人、海报、电车晚点、便利店），与时段天气吻合，不堆砌。
对话差异化：每个角色有固定语速和口头禅，波奇小声碎碎念、虹夏明快精准吐槽、凉短句电波、喜多元气连珠。
情感表达：用身体反应（肩膀放松、绞衣角、盯地板），禁止写"她感到幸福"。
推动方式：优先动作、停顿、眼神、对话，减少解释性旁白。
活人反应：被问话不全答——转移话题、答非所问、突然想起别的事。
场景节奏：日常像日常——有废话、有空档、有走神，不是每句都推动剧情。
禁止：散文式环境铺陈、题外独白、旁白抢戏、全员围着玩家转。
```

## 二、仙侠 / 古风

```
文风：传统仙侠，古风遣词，画面感强，张弛有度。
战斗：注重法术视觉冲击力，一招一式写清来路与去处，不写"大战三百回合"。
对话：称"前辈""道友""在下"，但不通篇文言——半文半白，读得懂为准。
景物：山、雾、松、钟声、剑光；一段最多两笔，不铺陈。
禁止：现代口语（"OK""搞定了"）、网络梗、系统面板式报数。
```

## 三、末世 / 生存

```
文风：冷、硬、短。环境先于人物——先写天、写废墟、写味道。
感官：嗅觉和听觉优先（铁锈味、风穿过断墙的哨音），视觉其次。
对话：短句，信息密度高，少形容词。
节奏：日常段落也要有"随时会出事"的底噪；不要连续两轮平安无事。
禁止：热血口号、救世主情结、无代价开挂。
```

## 四、悬疑 / 推理

```
文风：克制、精确。所有描写只写"看见的"，不写"推断的"。
线索：一条一轮，藏在动作和物件里，不点破。
对话：答非所问、停顿、转移话题是常态；关键信息用沉默交代。
禁止：上帝视角揭示动机、角色突然自白、"原来如此"式总结。
```

## 五、宫廷 / 宅斗

```
文风：含蓄、有礼数。称呼、位份、座次都是信息。
对话：话里有话，表面客气底下带刀；一句台词至少两层意思。
情绪：不写在脸上，写在手上（帕子、茶盏、袖口）。
禁止：现代口语、直白吵架、当面撕破脸（除非到高潮）。
```

## 六、青春治愈 / 回忆

```
文风：轻、慢、具体。用季节、衣服厚度、天什么时候黑来写时间。
情绪：留白。最高潮处不写满——写动作、写沉默、写窗外。
禁止：煽情排比、"我们终将长大"式升华、把悲剧写成浪漫。
```

## 七、赛博 / 科幻

```
文风：冷色调、高信息密度。术语可用但要克制，一段最多两个专有名词。
环境：霓虹、雨、广告牌、义体、数据流；写"旧"和"脏"，不写"炫"。
对话：省略主语、行业黑话、句子被通讯打断。
禁止：解释科技原理、说明书式旁白。
```

## 八、克苏鲁 / 恐怖

```
文风：不安感来自"不对劲"，不是来自血腥。
描写：先正常，再偏一格（多出来的一把椅子、不该在那儿的影子）。
认知：主角的描述可以自相矛盾，读者自己发现。
禁止：怪物详细外形、血浆描写、解释世界观设定。
```

## 九、战斗 / 热血

```
文风：短句、动词密集。节奏靠句子长短控制——快的时候一句话五个字。
战斗：写判断、写代价、写失误，不写"实力碾压"。
禁止：招式名堆砌、喊口号、无伤通关。
```

## 十、成人向（R18）

```
用词：直白具体，不回避、不含糊。器官用固定词，全文统一，不用"下面""那里"替代。
动作：一步一动，拆成微小环节，逐个写清接触、力度、反应。
声音：拟声词密集但不滥用，一句最多两个。
节奏：前戏、过程、余韵分明；余韵要写，不要一到高潮就切。
禁止：文艺化隐喻代替具体描写、跳过过程直接结果、把对方写成只发情的道具。
```

## 怎么改写成自己的

选一套后，按这张表改：

| 项 | 改成什么 |
|---|---|
| 基调 | 一句话，如"日常轻喜剧""冷硬末世" |
| 视角与长度 | 第一人称/第三人称；每轮 200~500 字 |
| 对话差异化 | 每个主要角色一句语速/口癖描述 |
| 情绪载体 | 身体反应还是动作还是环境 |
| 禁止清单 | 保留通用 AI 腔，再加该题材特有的（如仙侠禁现代词） |
| 每轮怎么写 | 开头给什么、中间推什么、结尾留什么 |

**不要照抄整段**——照抄的文风规则 AI 会当成模板腔，反而更假。改词、删句、加该卡特有的细节。
