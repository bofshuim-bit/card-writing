# 送审清单（按平台退回标准整理）

> 来源：平台审核通知原文（MMD 角色卡审核）。跟着本 skill 写，基本只会撞这三类。
> 每条都给了「审核怎么判」和「怎么改」，提交前逐条对。

---

## 一、有效设定字数不足 3000

**审核原文**

> 有效设定字数不足：实际有效设定少于 3000 字，需补充实质性内容。
> 世界观及背景设定过于简略：缺少具体的场景、地图区域、势力组织、社会背景、规则机制等内容，难以支撑角色互动与剧情发展。
> 角色人设过于简略：缺少对角色性格、经历、行为动机、人物关系及互动逻辑的具体设定。
> **注意：排版美化、状态栏、叙述规则、破甲、输出模板、示例、特化机制等辅助模块不计入有效设定字数。**

**怎么判**

数一数「真正描写世界和角色」的字数，**不含**：

- 美化 / 样式 / 状态栏协议
- 叙述规则、「禁止 OOC」这类行为准则
- 破甲句、输出模板、示例
- 特化机制（数值系统、战斗规则）

**怎么改**

按审核给的清单补，每条都要具体：

| 项 | 补什么 |
|---|---|
| 外貌 / 穿着 | 体型、面部特征、常见装扮风格 |
| 性格特征 | 核心性格、情绪倾向、应激反应 |
| 行为模式 | 说话方式、肢体习惯、处事风格 |
| 日常习惯 | 作息、爱好、忌讳 |
| 亲密 / 性设定 | 态度、边界、偏好倾向（成人向卡） |
| 互动关系 | 与主角/其他角色的关系定位、相处模式、情感逻辑 |

世界观侧补：具体场景、地图区域、势力组织、社会背景、规则机制。

**经验值**：单角色日常卡，人设正文 3000~4000 字比较稳；多角色卡每多一个核心角色加 1500 左右。这些字数最好放蓝灯（算有效设定），别堆在协议里。

## 二、长段连续叙述 / 小说化表达

**审核原文**

> 当前设定 / 世界书中部分内容存在连续叙述、信息混杂或小说化表达的问题，需要进一步整理。
> **注意小说化整改并非需要你减少字数描述。**

重点检查四种情况：

1. 大量内容以连续自然段展开，需要从整段文字中自行提取具体设定；
2. 一个段落中混合了多种不同信息（背景经历、性格、关系、能力、行为逻辑、世界规则等）；
3. 使用较多环境描写、动作描写、心理描写、过程描写或故事复述来间接表达设定；
4. **虽然已经换行或拆成多个短段，但每段仍属于连续叙述，没有进一步整理成独立设定。**

第 4 条是最容易漏的：换了行不等于拆开了，只要一段里还在讲「事情怎么发生」，就还是叙述。

**审核给的修改建议**

- 按类型整理：基本信息 / 外貌 / 性格 / 背景经历 / 人物关系 / 能力 / 行为逻辑 / 世界观 / 历史 / 社会规则 / 特殊机制
- 同一模块内部继续分点，**每条尽量只表达一类明确的信息**
- 剧情和背景可以保留，但改成**简洁的事件概述**，不要完整小说故事段落展开
- 不要求表格、不要求固定模板，重点是不同类型能清楚区分、直接读取

**改法对照**

❌ 小说式（一段混了性格+经历+关系）
```
她从小生活在严格的家庭里，父母对她要求很高，她从来没有体会过真正的自由，
这让她养成了把自己锁起来的习惯，也让她在面对关心时总是先退一步。
```

✅ 拆成三条，每条一类信息
```
性格：不主动开口，被搭话先低头。
经历：父母管得严，成绩不能掉出前三，交朋友要经过审核。
行为逻辑：被关心时先退一步，过几秒才回应。
```

## 三、缺少成年声明

**审核原文**

> 凡出现外貌看似、看上去、外表年龄等未满 18 岁的年龄描述，均须在标题或简介明确标注：**所有角色均已成年**。

**怎么改**

- 在**标题或简介**里写「所有角色均已成年」，不是写在人设里
- 只要卡里出现「高中生」「学生」「少女」「看起来十六七岁」这类描述，就必须加
- 人设里也交代一句更稳：「本卡所有角色均为成年人」

## 四、提交前逐条过

- [ ] 有效设定（不含美化/协议/规则/示例）≥ 3000 字
- [ ] 世界观有具体场景、区域、势力、社会背景、规则机制
- [ ] 角色有外貌、性格、行为模式、日常习惯、关系逻辑
- [ ] 没有连续叙述段落，每条只讲一类信息
- [ ] 剧情是事件概述，不是小说段落
- [ ] 有「所有角色均已成年」标注（标题或简介）
- [ ] 没有 `#` `*` `-` `>` 等 Markdown 符号
- [ ] 人设里没有和世界书重复的设定
