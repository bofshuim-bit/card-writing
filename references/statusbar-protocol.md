# 状态栏协议设计

## 一、协议的形态

每轮正文结束，AI 另起一行输出锚点，再逐行输出 `[#键=值#]`：

```
<GC_UI>
[#轮次=0#]
[#名=张楚岚#]
[#炁=71#]
...
```

- 锚点（`<GC_UI>` 或自定义 token）由正则换成卡片的宿主元素
- `[#键=值#]` 由信标规则换成隐藏 span，卡片读它
- **值里禁止出现 `#` `[` `]`**，否则数据断开
- **每轮全量**，没变的也要重写

## 二、键怎么设计

分四组：

**1. 场景组**（4~6 个）
```
[#日期=03月 · 星期三#]
[#时间=上午 10:20#]
[#地点=教学楼 · 高二（3）班#]
[#天气=晴 · 18°C#]
[#事件=课间休息#]
[#下节=数学课 · 16:00#]
```

**2. 状态组**（2~4 个，才是进度条）
```
[#炁=0~100#]
[#心=0~100#]
```
不要给所有东西都上数值，两条就够。多了变成属性表。

**3. 关系组**
```
[#关系=穗穗:初次认识;父亲:如常#]
[#动态=穗穗:在后山啃黄瓜#]
```
关系用**文字档位**（初次认识/开始熟悉/相处融洽/彼此信任/有些话还没说），
不要写"好感 87"——数字会立刻让人出戏。档位由剧情决定，不许每轮乱升。

**4. 行动组**
```
[#选项A=下课回头搭话#]
[#选项B=放学等她一起走#]
[#选项C=装作没看见#]
[#选项D=去问同学她是谁#]
```
3~4 条，方向必须不同：至少一条往前推、一条往回收、一条问出来。
禁止"看着她的背影"这种没动作的空选项。

## 三、轮次

```
[#轮次=0#]
```
- 从 0 开始（开场白是 0），每轮 +1
- **只是计数，不驱动剧情**
- 界面**以 AI 输出为准**，不要按 DOM 位置自己数——消息重发、平台插入节点都会算错
- 重发同一条消息时数值不变，因为渲染的是同一条消息的数据

## 四、角色块（多角色卡）

只输出**本轮出场**的角色，未出场不输出：

```
[#波奇关系=认识#][#波奇值=28#][#波奇羁绊=普通朋友#][#波奇社恐=70#][#波奇心情=紧张#]
[#波奇状态=抱着吉他缩在墙角#][#波奇穿着=校服外套拉链拉到下巴#][#波奇心声=完了完了#]
```

- 每人 5~8 个键，别更多
- `羁绊` 是具体称谓（普通朋友/损友/暧昧对象/师徒），不是数字
- `心声` 一句话，是角色此刻在想什么，最能提神
- 角色多了会撑爆预算：8 人 × 8 键 = 64 行，只适合卡牌类；日常卡 3~5 人足够

## 五、和界面的对应

协议设计完，先画一遍"哪个键显示在哪"：

| 键 | 界面位置 |
|---|---|
| 轮次 | 卡头小徽章 |
| 名/身份 | 卡头 |
| 炁/心 | 两条进度条 |
| 状/地/时/阶/任/钱 | 数据行 |
| 关系 | 胶囊一排（点开看 NPC 详情） |
| 动态 | NPC 详情里的近况 |
| 线索/物 | 侧边栏对应页签 |
| 选项 | 卡底按钮，点击写入输入框 |

对不上的键就是白写。

## 六、示例（日常卡）

```
<GC_UI>
[#日期=03月 · 星期三#]
[#轮次=0#]
[#时间=上午 10:20#]
[#地点=教学楼 · 高二（3）班#]
[#天气=晴 · 18°C#]
[#事件=课间休息#]
[#下节=数学课 · 16:00#]
[#计划=放学后要不要去便利店#]
[#记忆=她坐在我后桌，低着头翻书。#]
[#关系=穗穗:初次认识#]
[#心事=想问她又没问出口。#]
[#物件=校服|她的眼镜#]
[#伏笔=她说「为了找一个人」#]
[#选项A=下课回头搭话#]
[#选项B=放学等她一起走#]
[#选项C=装作没看见#]
[#选项D=去问同学她是谁#]
```

## 七、检查

- [ ] 值里没有 `# [ ]`
- [ ] 每轮全量
- [ ] 关系是文字档位
- [ ] 选项方向不同
- [ ] 每个键都能在界面上找到位置
- [ ] 键名和卡片读取的完全一致（大小写、中文写法）
