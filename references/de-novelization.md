# 去小说化

> 去小说化不是让文字变丑，是让文字变准。准，是给 AI 看的文字的第一要求。
>
> 去小说化，就是**把「小说式的叙述」改成「规则式的指令」**。

小说式叙述是连续的、有修辞的、有情绪铺垫的、讲究文学性的文字。它适合读者阅读，但不适合 AI 执行。
AI 需要的是明确的、无歧义的、可以直接转化为行为的指令。

---

## 一、把连续叙述拆成条目

**小说写法**
```
她站在门口，手里端着一杯咖啡，靠在墙上等他回来，眼神里带着一丝疲惫。
```

**去小说化后**
```
深夜等 {{user}} 回来时，靠在仓库门口，手里端着一杯热咖啡。
不主动说话。
累的时候用食指揉眉心。
```

拆成三条，每一条都是 AI 可以直接执行的行为。

---

## 二、把形容词换成具体行为

**小说写法**
```
她很温柔。
```

**去小说化后**
```
即使对陌生人也会先问「你有没有受伤」，而不是「你是什么人」。
```

形容词 AI 不知道怎么表现，行为可以直接写。

---

## 三、把情绪描写换成动作指令

**小说写法**
```
她心里很难过，眼泪在眼眶里打转。
```

**去小说化后**
```
听到消息后继续把手里的碗洗完。
水凉了才发现自己一直没开热水。
```

用动作传递情绪，AI 可以执行。

---

## 四、把场景描写压缩成感官标签

**小说写法**
```
阳光透过破旧的窗纸洒进来，照在土坯墙上，灰尘在光柱里缓缓飘浮，
空气中有一种陈旧而安静的味道。
```

**去小说化后**
```
环境优先感官：风沙刺痛、黄土灰尘、煤烟味、酒精棉球味、老槐树阴凉、火车汽笛声。
```

给 AI 一组感官标签，让它根据当前场景自行调用。

---

## 五、把规则写成命令句

**小说写法**
```
AI 应该注意不要让角色做出不符合性格的事情，这样才能保持角色的真实性。
```

**去小说化后**
```
禁止 OOC。每个 NPC 严格按照性格描写行动。
```

命令句，没有解释，没有铺垫。

---

## 六、把背景故事压缩成事实清单

**小说写法**
```
她从小生活在严格的家庭里，父母对她的要求很高，她从来没有体会过真正的自由，
这让她养成了把自己锁起来的习惯。
```

**去小说化后**
```
从小父母管得严，成绩不能掉出前三，交朋友要经过审核。
从小学到高中没有过一个真正意义上的朋友。
她拒绝你，不是因为讨厌你，是因为她的世界里没有「可以答应」这个选项。
```

事实清单，每一条都是 AI 可以直接引用的设定。

---

## 核心判断标准：写完一段问三句

1. **这段话是在「讲故事」还是在「下指令」？**
   讲故事，AI 会把它当小说读，不会当规则执行。改。

2. **有没有形容词、修辞、情绪铺垫可以删？删掉之后信息是否完整？**
   完整就删。

3. **能不能拆成更短的条目？每条只传达一类信息？**
   能拆就拆。

---

## 另一个被拒原因：符号洁癖

人设、世界书、开场白是**纯文本字段**，不是 Markdown 文档。

会被判为格式问题的：

```
# 一级标题
## 二级标题
**加粗**
*强调*
- 列表项
1. 有序列表
> 引用
```

**改成纯文本**：用 `【】` 分节，用换行分条，用「·」或直接换行做条目，不要用 `#` `*` `-` `>`。

**唯一例外：状态栏协议。** `[#键=值#]` 里的 `#` 是数据总线的定界符，必须保留；
它由正则换成隐藏 span，不会出现在读者眼前。除此之外的 `#`（标题、井号）一律删。

```
【世界类型】
现实向高中校园，二十一世纪一十年代。没有超自然元素。
约束是校规、成绩、家庭与面子。
```

判断标准：把这些文字复制到记事本里，看起来是不是干净的纯文本。带一堆 `#` `*` 的，先删符号再送审。

---

## 检查清单

- [ ] 通篇没有 Markdown 符号（`#` `*` `-` `>`）；协议里的 `[#键=值#]` 不算
- [ ] 没有连续三句以上的叙述段落
- [ ] 形容词能换成行为的都换了
- [ ] 情绪用动作写，不写「她很难过」
- [ ] 场景是感官标签，不是景物散文
- [ ] 规则是命令句，不是「应该注意」
- [ ] 背景是事实清单，不是故事
- [ ] 每条只讲一件事
